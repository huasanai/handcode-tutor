## 字段说明

| 字段 | 必填？ | 说明 |
|---|---|---|
| `type` | ✅ | 固定 `howto` |
| `status` | ✅ | `draft`（用户未确认）/ `stable`（用户已确认无质疑） |
| `date` | ✅ | 创建日期 YYYY-MM-DD |
| `tags` | ✅ | 至少含技术标签 + 项目标签 |
| `project` | 可选 | wikilink，指向你笔记库里的相关项目入口 md |
| `problem` | 可选 | wikilink，指向这次实操在解什么 Problem |

## 结构选取建议

- 涉及 2 个以上**关键概念** → 每个一节（"二、三、..."）
- 不涉及多概念，只是一套流程 → 跳过概念节，直接 "完整流程 → 踩坑 → 深入"
- 没有踩坑 → 不强行写
- 至少保留：**问题清单 + 完整流程 + 下一步**
